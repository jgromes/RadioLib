Detailed Description

Client for SSDV image transmission and reception. Encodes a baseline JPEG into 256-byte SSDV packets and reassembles received packets into a JPEG. The JPEG must be baseline DCT, greyscale or YCbCr, with dimensions that are multiples of 16 (max. 4080 x 4080). Encoder and decoder are derived from ssdv by Philip Heron, https://github.com/fsphil/ssdv (GPL-3.0).

int16_t SSDVClient::setImage ( const uint8_t *  jpegData,
size_t  jpegLen,
uint8_t  quality = 4,
int16_t  imageId = -1 
)

Encode a JPEG image into SSDV packets. Any previously loaded image is discarded. The packets are stored on heap (numPackets() * 256 bytes), so the JPEG may be released afterwards. With RADIOLIB_STATIC_ONLY, a static buffer of RADIOLIB_SSDV_MAX_PACKETS packets is used instead, which only one SSDVClient instance can hold at a time. Does not affect an image that is being received.

Parameters
jpegDataComplete JPEG file.
jpegLenLength of the JPEG in bytes.
qualityQuality level 0 - 7, corresponding to JPEG quality 13, 18, 29, 43, 50, 71, 86 and 100. Defaults to 4.
imageIdImage ID 0 - 255, or -1 to increment the ID of the previous image. Defaults to -1.
Returns
Status Codes

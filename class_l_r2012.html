LR2012 Class Reference

Derived class for LR2012 modules. The LR2012 is the sub-GHz member of the LR20xx family: it shares the LR2021 command set, but has no high-frequency front end and no FLRC, O-QPSK, Bluetooth LE or Z-Wave support. More...

 Write a payload into the transmit buffer without staging or starting a transmission. This allows the payload write, which is the slowest part of starting a transmission, to be done while the radio is busy with something else - during a channel scan, for example. Detailed Description

Derived class for LR2012 modules. The LR2012 is the sub-GHz member of the LR20xx family: it shares the LR2021 command set, but has no high-frequency front end and no FLRC, O-QPSK, Bluetooth LE or Z-Wave support.
